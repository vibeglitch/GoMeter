# Security Policy

## Supported Versions

Security updates and patches are actively maintained for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.6.x   | :white_check_mark: |
| < 1.6.0 | :x:                |

---

## Reporting a Vulnerability

The GoMeter team takes security vulnerabilities seriously.

If you believe you have discovered a vulnerability in GoMeter (CLI, MCP Server, or VS Code Extension):

1. **Do NOT open a public GitHub issue.**
2. Send an email to the repository owner at `polisetty465@gmail.com` with:
   - A clear description of the vulnerability.
   - Proof-of-concept steps or code to reproduce the issue.
   - The impact of the vulnerability.
3. You will receive an acknowledgment within 48 hours.
4. We will coordinate a patched release and credit you in our release notes if requested.
